# 🤖 Агент поиска Python-вакансий (бесплатный, в Telegram)

Агент сам ищет вакансии **Python backend (Junior / Trainee, ~1 год опыта, remote)**, отсеивает лишнее, оценивает каждую через ИИ (Google Gemini, бесплатно) и присылает подходящие в Telegram. Управлять им можно прямо из чата командами. Всё работает на GitHub Actions: свой сервер не нужен.

---

## 1. Как это работает

```
Каждые 3 часа (GitHub Actions)
 │
 ├─ 1. Бот: читает ваши команды из Telegram (/pause, /addcompany ...)
 │
 ├─ 2. Сбор вакансий
 │     ├─ LinkedIn + Indeed            (python-jobspy)
 │     ├─ Remote-доски с открытым API  (Remotive, Arbeitnow, Jobicy, Working Nomads, RemoteOK)
 │     ├─ RSS                          (WeWorkRemotely, Python.org, DOU, Djinni)
 │     └─ Сайты компаний               (Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee
 │                                      + запасной режим для обычных страниц /careers)
 │
 ├─ 3. Жёсткая фильтрация в Python (без ИИ, бесплатно)
 │     ├─ уже виденные вакансии (seen_jobs.json)
 │     ├─ стоп-слова в названии (Senior, Lead, Java, QA ...)
 │     └─ в тексте нет Python / Django / FastAPI / Flask
 │
 ├─ 4. Оценка ИИ (Gemini): балл 1–10, причина по-русски, совпавшие технологии
 │
 └─ 5. Оценка ≥ порога → сообщение в Telegram с кнопками ⭐ ✅ 🙈
```

Каждые 30 минут отдельный короткий запуск обрабатывает только команды бота (вакансии при этом не ищутся).

## 2. Файлы проекта

| Файл | Что делает |
|---|---|
| `scraper.py` | Главный скрипт: сбор → фильтр → ИИ → Telegram |
| `sources.py` | Все источники вакансий и определение системы найма компании |
| `bot.py` | Обработчик команд Telegram |
| `common.py` | Общие функции, настройки по умолчанию |
| `config.json` | Ваши настройки (порог, запросы, стоп-слова, профиль). Меняется командами бота |
| `companies.json` | Компании, чьи сайты проверяются. Меняется командами бота |
| `seen_jobs.json` | Память: какие вакансии уже обработаны (создаётся сам) |
| `state.json` | Служебное: позиция в Telegram, сохранённые вакансии, итоги запуска (создаётся сам) |
| `requirements.txt` | Библиотеки Python |
| `.github/workflows/job_agent.yml` | Расписание и запуск в GitHub Actions |

## 3. Установка по шагам

### Шаг 1. Создайте Telegram-бота

1. В Telegram найдите **@BotFather** (с синей галочкой) и отправьте `/newbot`.
2. Введите имя бота (любое, например `Job Agent`).
3. Введите username: латиницей, должен заканчиваться на `bot` (например `my_python_jobs_bot`).
4. BotFather пришлёт **токен** вида `123456789:AAH...`. Это пароль от бота: никому не показывайте и не публикуйте в коде. Если токен утёк, отправьте BotFather `/revoke`.
5. Откройте своего бота и нажмите **Start** (или отправьте `/start`). Без этого бот не сможет вам писать.

### Шаг 2. Узнайте свой chat id

1. В браузере откройте (подставьте свой токен, слово `bot` перед токеном оставьте):
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
2. Найдите кусок `"chat":{"id":123456789,...` и скопируйте число: это ваш **chat id**.
3. Если пришло `"result":[]`, напишите боту любое сообщение и обновите страницу.

### Шаг 3. Получите бесплатный ключ Gemini

1. Откройте **aistudio.google.com**, войдите в Google-аккаунт.
2. **Get API key → Create API key**. Скопируйте ключ.
3. Платить не нужно. Бесплатные лимиты Google периодически меняются, актуальные смотрите в AI Studio.

### Шаг 4. Создайте репозиторий на GitHub

1. **New repository**, имя любое (например `job-agent`).
2. Видимость:
   * **Public**: минуты GitHub Actions бесплатны без ограничений. Но `config.json` (ваш профиль, запросы) и список вакансий будут видны всем. Секреты (токены) остаются скрытыми.
   * **Private**: данные скрыты, но на бесплатном тарифе около 2000 минут Actions в месяц. Настройки по умолчанию (поиск каждые 3 ч + команды каждые 30 мин) могут их превысить, см. раздел 8.
3. Загрузите все файлы проекта (**Add file → Upload files**).
   * Папка `.github` начинается с точки и в Finder / Проводнике может быть **скрыта** (на Mac: `Cmd + Shift + .`).
   * Надёжный способ: **Add file → Create new file**, в поле имени введите `.github/workflows/job_agent.yml` (слэши сами создадут папки) и вставьте содержимое файла.

### Шаг 5. Разрешите Actions коммитить файлы

**Settings → Actions → General → Workflow permissions → Read and write permissions → Save.**
Без этого агент не сможет сохранять память (`seen_jobs.json`) и настройки, и вакансии начнут повторяться.

### Шаг 6. Добавьте секреты

**Settings → Secrets and variables → Actions → New repository secret.** Три секрета, имена строго такие:

| Имя | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен от BotFather |
| `TG_CHAT_ID` | ваш chat id из шага 2 |
| `GEMINI_API_KEY` | ключ из AI Studio |

### Шаг 7. Первый запуск

1. Вкладка **Actions**. Если GitHub просит включить workflows, нажмите зелёную кнопку.
2. Слева выберите **Job Agent → Run workflow → Run workflow**.
3. Через минуту откройте запуск и посмотрите логи шагов. В `Search vacancies` будут строки вида `Remote-агрегаторы: 40 vacancies`, `Candidates after filtering: 17`, `[8/10] Junior Python Developer @ ...`.
4. В Telegram придёт справка бота (ответ на ваш `/start`) и первые вакансии.

> На первом запуске накопится много вакансий. Агент оценивает не больше 25 за запуск (сначала те, где в названии junior/trainee/intern), остальные подхватит следующий запуск.

## 4. Команды бота

Бот работает без сервера: команды обрабатываются при ближайшей проверке (обычно **до 30 минут**). Нужен ответ сразу, отправьте `/run` или запустите Run workflow вручную. Бот слушается только вашего chat id.

| Команда | Что делает |
|---|---|
| `/help` | Список команд |
| `/status` | Состояние, настройки, итоги последнего запуска |
| `/run` | Запустить поиск прямо сейчас |
| `/pause` · `/resume` | Поставить поиск на паузу / продолжить |
| `/minscore 7` | Минимальная оценка ИИ для отправки (1–10) |
| `/hours 24` | Брать вакансии не старше N часов |
| `/summary on` · `off` | Присылать короткий итог после каждого запуска |
| `/source rss off` | Включить/выключить источник: `jobspy`, `aggregators`, `rss`, `companies` |
| `/terms` · `/addterm junior django developer` · `/delterm 2` | Поисковые запросы для LinkedIn/Indeed |
| `/stops` · `/addstop php` · `/delstop senior` | Стоп-слова в названии вакансии |
| `/profile` · `/setprofile текст` | Описание вас для ИИ (стек, уровень, английский, формат) |
| `/companies` | Список отслеживаемых компаний |
| `/addcompany ссылка` | Добавить компанию по ссылке на её страницу вакансий |
| `/addcompany greenhouse:gitlab` | Добавить, если знаете систему и название |
| `/addcompany gitlab` | Бот сам попробует найти компанию в известных системах |
| `/delcompany gitlab` | Удалить компанию (по названию или номеру) |
| `/saved` · `/applied` | Сохранённые вакансии / куда откликнулись |

**Кнопки под вакансией:** ⭐ Сохранить, ✅ Откликнулся, 🙈 Скрыть (удаляет сообщение). Повторное нажатие снимает отметку.

## 5. Сайты компаний: как это работает

Большинство компаний публикуют вакансии через систему найма (ATS), у которой есть **открытый JSON-API**. Агент ходит прямо в него: это точнее и стабильнее, чем разбирать HTML.

| Система | Как выглядит ссылка на вакансии |
|---|---|
| Greenhouse | `boards.greenhouse.io/<название>` |
| Lever | `jobs.lever.co/<название>` |
| Ashby | `jobs.ashbyhq.com/<название>` |
| Workable | `apply.workable.com/<название>` |
| SmartRecruiters | `jobs.smartrecruiters.com/<название>` |
| Recruitee | `<название>.recruitee.com` |

**Как добавить компанию:**

1. Найдите страницу «Careers / Вакансии» на сайте компании.
2. Отправьте боту: `/addcompany https://company.com/careers`.
3. Бот откроет страницу, найдёт в ней систему найма, проверит, что вакансии читаются, и ответит, сколько открыто вакансий и сколько из них про Python.

Если система не определилась, включается **общий режим**: бот собирает ссылки на странице, в тексте которых есть python / django / fastapi / backend. Он не работает на сайтах, где список вакансий рисуется JavaScript-ом. В этом случае бот скажет, что вакансий не найдено, и не добавит компанию. Тогда откройте страницу вакансий в браузере: если в адресной строке виден `greenhouse`, `lever`, `ashby` и т.п., добавьте по формату `/addcompany greenhouse:название`.

Для сайтов компаний агент берёт **все открытые** вакансии про Python (а не только за последние сутки), а память `seen_jobs.json` не даёт присылать одно и то же дважды.

**Стартовый список** в `companies.json` (GitLab, Grammarly, Elastic, MongoDB, Cloudflare, Twilio, Stripe, Spotify, Notion, Ramp) составлен по моим данным о том, какую систему используют эти компании, и **не проверен живыми запросами**: у части компаний название на сайте найма или сама система могли измениться. Неверные записи не ломают запуск, в логах будет `Source <компания> failed: 404`. Удалите их через `/delcompany` и добавьте свои.

**Кого добавить для украинского и европейского рынка:** Grammarly, GitLab, Preply, Ciklum, SoftServe, EPAM, GlobalLogic, Intellias, N-iX, Lohika, Luxoft, Genesis, Competera, Reface, Jooble. У части из них собственные сайты вакансий без открытого API: на таких добавление может не сработать, это нормально.

## 6. Источники

**Подключены автоматически**

| Источник | Что даёт | Примечание |
|---|---|---|
| LinkedIn, Indeed | Широкий поиск по запросам из `/terms` | Иногда блокируют запросы с серверов GitHub, тогда будет пусто |
| Remotive, Arbeitnow, Jobicy, Working Nomads, RemoteOK | Только удалённые вакансии | Открытые API |
| WeWorkRemotely, Python.org Jobs | Remote и Python-вакансии | RSS |
| DOU, Djinni | Украинский рынок | RSS: ссылки могут меняться или закрываться защитой |
| Сайты компаний | См. раздел 5 | Через `/addcompany` |

**Не подключены, но стоит смотреть вручную** (нет проверенного открытого API/RSS, который я мог бы подключить без риска, что он сломается): Wellfound, Himalayas, Welcome to the Jungle, justjoin.it, NoFluffJobs, Work.ua, Robota.ua, Remote Rocketship, а также раздел вакансий в Telegram-каналах по Python. Если у какого-то сайта есть RSS-лента по вашему поиску, добавьте её в `rss_feeds` в `config.json`.

Если один источник упал (сайт недоступен, поменялся формат), остальные продолжают работать. Сбои видны в логах, а при `/summary on` и в Telegram.

## 7. Настройка через config.json

Всё это можно менять и командами бота, и руками в файле (кнопка ✏️ на GitHub).

| Поле | Значение по умолчанию | Смысл |
|---|---|---|
| `paused` | `false` | Пауза |
| `min_score` | `7` | Порог оценки ИИ для отправки |
| `hours_old` | `24` | Свежесть вакансий (для remote-досок и RSS берётся втрое больше, дубли отсекает память) |
| `max_llm_per_run` | `25` | Сколько вакансий оценивать за один запуск |
| `llm_pause_sec` | `7` | Пауза между запросами к Gemini (защита от ошибки 429) |
| `gemini_model` | `gemini-2.5-flash` | Модель |
| `send_summary` | `false` | Итог после каждого запуска |
| `timezone` | `Europe/Kyiv` | Для времени в `/status` |
| `sources` | все `true` | Включение источников |
| `search_terms` | 5 запросов | Для LinkedIn/Indeed |
| `jobspy_location` | `Europe` | Регион поиска LinkedIn/Indeed |
| `stop_words` | см. файл | Вакансия отбрасывается, если слово есть в названии |
| `rss_feeds` | 4 ленты | Название → ссылка |
| `profile` | ваш профиль | Текст, по которому ИИ ставит оценку |

**Про Senior:** в стоп-словах сейчас есть `senior`, потому что вы ищете джун/трейни. Если хотите видеть и Senior-вакансии, отправьте `/delstop senior`.

**Как ИИ ставит оценку:** 9–10 это Junior/Trainee, Python backend, remote и доступно из Украины/Европы, английский не выше B2. 1–3 это Senior или 3+ года опыта, офис/релокация, remote только для другой страны, требуется английский C1+. Подстроить можно в `/setprofile`.

## 8. Лимиты и расходы

* **Gemini (бесплатный тариф):** есть лимиты на запросы в минуту и в день. По умолчанию: до 25 оценок за запуск, пауза 7 с, 8 запусков в сутки ≈ 200 запросов. Если в логах `429` / `RESOURCE_EXHAUSTED`, уменьшите `max_llm_per_run` или увеличьте `llm_pause_sec`.
* **GitHub Actions:** публичный репозиторий не ограничен. В приватном бесплатном около 2000 минут в месяц. Запуск команд (каждые 30 мин) занимает примерно минуту, полный поиск несколько минут, так что при настройках по умолчанию лимит легко превысить. Чтобы сократить:
  * в `job_agent.yml` замените `"7,37 * * * *"` на `"7 * * * *"` (команды раз в час) и `"0 */3 * * *"` на `"0 */4 * * *"`;
  * **строка в условиях `if:` (`'7,37 * * * *'`) должна совпадать с cron-строкой команд символ в символ**, меняйте её в обоих местах;
  * либо сделайте репозиторий публичным.
* GitHub запускает расписание не точно: задержки в десятки минут бывают. Если в репозитории долго нет активности, GitHub может отключить запуски по расписанию: тогда на вкладке Actions нажмите **Enable workflow**.

## 9. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Бот молчит | Нажимали Start у бота? Верны ли `TG_BOT_TOKEN` и `TG_CHAT_ID`? Помните про задержку до 30 минут: проверьте вкладку Actions, были ли запуски |
| `Missing secrets` в логах | Имена секретов написаны точно: `GEMINI_API_KEY`, `TG_BOT_TOKEN`, `TG_CHAT_ID` |
| Вакансии повторяются | Не включены Read and write permissions (шаг 5) или `seen_jobs.json` не коммитится |
| `jobspy ... 429/403` или пусто | LinkedIn/Indeed блокируют серверы GitHub. Остальные источники работают, при желании отключите: `/source jobspy off` |
| `Source <компания> failed: 404` | Неверное название в `companies.json`. `/delcompany`, затем `/addcompany ссылка` |
| `Gemini rate limit (429)` | См. раздел 8 |
| Пришло слишком мало / много | `/minscore 6` или `/minscore 8`, поправьте стоп-слова и профиль |
| Всё остановилось само | Вкладка Actions → Enable workflow (раздел 8) |

**Проверка локально (необязательно):**

```bash
pip install -r requirements.txt
export GEMINI_API_KEY=... TG_BOT_TOKEN=... TG_CHAT_ID=...    # Windows PowerShell: $env:GEMINI_API_KEY="..."
python bot.py       # обработать команды
python scraper.py   # собрать и отправить вакансии
```

## 10. Честные ограничения

* Код проверен **офлайн на подставных данных** (парсеры компаний, фильтры, команды бота, кнопки, повторный запуск без дублей). С реальными LinkedIn, Gemini и Telegram он в моей среде не соединялся, поэтому первый запуск смотрите по логам.
* Адреса API и RSS сторонних сайтов могут меняться. Это не ломает весь агент, но конкретный источник может перестать отдавать данные.
* ИИ-оценка это подсказка, а не приговор: иногда стоит заглянуть и в вакансии с оценкой 5–6 (`/minscore 5`).
* Агент ищет и присылает вакансии, но сам не откликается.
